# Hostel Management System

## Project Overview
The Hostel Management System (HMS) is a web-based software engineering mini-project developed at PES University. It aims to simplify hostel administration by managing student records, room allocation, hostel fees, complaints, leave requests and visitor records through a centralised system.

## Objectives
- Simplify room and bed allocation.
- Maintain student and hostel records.
- Manage hostel fee records and payment status.
- Track complaints and maintenance requests.
- Manage leave and outpass requests.
- Maintain visitor records and publish hostel announcements.
- Provide role-based access to hostel information and administrative functions.

## Core Features
- User authentication and role-based access.
- Student record management.
- Room and bed availability and allocation.
- Hostel fee and payment record management.
- Complaint and maintenance request management.
- Leave and outpass management.
- Visitor record management.
- Announcements and notifications.
- Administrator and warden dashboards and reports.

## User Roles

| Role | Responsibilities |
|---|---|
| Student | View room details, fee status, announcements and submit requests or complaints. |
| Warden | Manage allocations, review student requests and oversee hostel operations. |
| Administrator | Manage users, hostel records, fee records and reports. |
| Maintenance Staff | View assigned maintenance requests and update their status. |

## Technology Stack
- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Node.js and Express.js
- **Database:** MySQL
- **Version Control:** Git and GitHub

## Project Scope
The initial version focuses on the core hostel management workflows. Integration with external payment gateways and SMS services is optional and is not part of the guaranteed initial scope.

## Development Workflow
